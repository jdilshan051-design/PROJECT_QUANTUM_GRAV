1. **🎙️ Synthetic Cockpit Voice & Web Audio Avionics (SpaceX & Tesla Standard):**  
   Pure in-browser Web Audio synthesized chimes, beeps, engine rumble, and an AI speech synthesizer calling out flight checkpoints (*"Audio Avionics online"*, *"Spacetime curvature anomaly detected"*, etc.) with a live toggle.

2. **📼 Supabase Black Box Telemetry Replay System:**  
   Fetches past flight mission records directly from the Supabase PostgreSQL cloud vault and re-drives the cockpit sliders, warp tensors, and graphs in real time!

3. **🌍 NASA JPL 3D Orbital Trajectory Digital Twin (Three.js):**  
   Interactive 3D Earth globe with real-time Keplerian Low Earth Orbit (LEO 51.6°) trajectory tracking, apogee/perigee markers, and orbital velocity vectors.

4. **📱 SpaceX "Crew Dragon" Touch UI Mode:**  
   One-click transition from dark retro-cyberpunk to SpaceX's signature high-contrast white & cyan glassmorphism touchscreen interface.

5. **🚨 NASA / SpaceX Launch Abort System (LAS):**  
   Full emergency abort sequence with klaxon sirens, animated plasma core decoupling, and automated failsafe countdown.

6. **⚡ ARINC 429 High-Frequency Telemetry Bus:**  
   Fast streaming avionics loop simulating military/aerospace ARINC 429 digital data buses.

* **Database & Telemetry:** Supabase (PostgreSQL with transaction pooler)
* **Hosting & CI/CD:** GitHub Pages (Frontend), Vercel Serverless (Backend)
