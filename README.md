* **Frontend:** Vanilla HTML5, Modern CSS (TailwindCSS), Three.js (Holographic 3D Renders), Chart.js

* **Machine Learning / AI:** PyTorch Actor-Critic PPO Architecture, Physics-Informed Neural Networks (PINN)
* **Database & Telemetry:** Supabase (PostgreSQL with transaction pooler)
* **Hosting & CI/CD:** GitHub Pages (Frontend), Vercel Serverless (Backend)
